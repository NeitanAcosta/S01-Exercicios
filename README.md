# 📚 Exercícios Práticos de Programação

Este repositório reúne as listas de exercícios desenvolvidas ao longo da disciplina, organizadas por semana e contendo soluções implementadas em diferentes linguagens de programação, conforme os requisitos de cada atividade.

O objetivo é registrar a evolução dos conteúdos estudados, aplicando conceitos de lógica, algoritmos, programação orientada a objetos e programação funcional.

---

## 📂 Estrutura do Repositório

As atividades estão organizadas em pastas semanais:

```text
📦 Exercicios-Praticos
 ┣ 📂 Semana_01
 ┃ ┣ 📜 Exercicio1.ext
 ┃ ┣ 📜 Exercicio2.ext
 ┃ ┗ 📝 IA_REPORT.md
 ┣ 📂 Semana_02
 ┃ ┣ 📜 Exercicio1.ext
 ┃ ┣ 📜 Exercicio2.ext
 ┃ ┗ 📝 IA_REPORT.md
 ┗ 📂 Semana_03
   ┗ ...
```

Cada pasta contém os arquivos-fonte dos exercícios propostos para a respectiva semana.

---

## 🤖 Uso de Inteligência Artificial

Quando permitido pela atividade, é incluído um arquivo `IA_REPORT.md` contendo:

* Identificação do aluno;
* Ferramenta de IA utilizada;
* Histórico de prompts;
* Respostas obtidas;
* Relatório de aprendizado e utilização da ferramenta.

O objetivo é garantir transparência no uso de ferramentas de Inteligência Artificial durante o desenvolvimento das atividades.

---

## 🎯 Objetivos das Atividades

As listas de exercícios buscam desenvolver habilidades relacionadas a:

* Resolução de problemas computacionais;
* Implementação de algoritmos;
* Estruturas de dados básicas;
* Programação Orientada a Objetos;
* Programação Funcional;
* Boas práticas de desenvolvimento.
